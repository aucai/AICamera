# AI拍照助手

一个安卓相机 App，拍照时实时给出**构图、姿势、光线**建议，并像手机厂商的 AI 相机一样按场景自动调色、虚化背景。识别模型（MediaPipe 姿态、物体、场景分类、人像分割）都在手机本地运行，不联网。

## 功能

交互参考了华为「AI 辅助构图」「AI 场景识别」、三星「Shot suggestions」、OPPO「LUMO 灵感构图」和 iPhone 水平仪：

- **AI 场景识别**：结合图像分类模型（1000 类）、物体检测（80 类）、画面颜色和相机曝光（判断室内 / 户外），识别人像、美食（能认出披萨、汉堡、火锅等）、猫狗（能认出金毛、柯基、狸花猫等常见品种）、花卉、绿植、蓝天、日落、夜景、雪景、水边、山景、建筑、文档、室内等，左上角显示「美食 · 披萨」「狗 · 柯基」这样的标签。只有户外亮度才会认成风景类场景。
- **按场景自动调色**（顶部「美化」开关，默认开）：不是简单滤镜，而是分区域调整——影调（对比、暗部、高光）、自然饱和度（保护肤色），以及针对性的颜色：蓝天更深、绿植更绿、美食更暖更有食欲、日落更浓。Android 13 及以上取景画面和成片效果完全一致（GPU 实时渲染）；更老的手机取景画面是近似效果。点「风格」标签可以手动选（原图、人像、美食、风光、清新、胶片、黑白）。
- **人像背景虚化**：拍人时自动把人抠出来、虚化背景（取景画面里手机拿稳时就能看到效果），成片按全分辨率处理、边缘贴合头发和肩膀。人物下方的「背景虚化」可以关掉。
- **自动调光补光**：以人脸为准（没有人就看场景）每次调 1/3 档曝光，最多 ±2EV；雪景自动提亮、日落稍微压暗、文档提亮；逆光或暗光下拍离得不远的人时自动打闪光灯（前置用屏幕补光），其余情况在照片里做暗部提亮。
- **瞄准式构图**：识别到主体后，算一次推荐构图并锁定。画面中间有一个固定的圈，场景里有一个目标点（跟着场景走）。移动手机把圆点对进圈里 → 变黄并轻震 → 相机拉近完成构图（最多 2 倍，避免画质变差）→ 自动裁成合适的画幅（美食 / 花草 1:1，横拿拍风景 16:9），框外实时压暗。
- **双构图**（拍人时）：「人物特写」会拉近突出人物，「人景合一」不变焦、把人放在环境的三分线上。
- **角度提示**：拍全身建议微微仰拍、拍美食斜 45°、拍宠物蹲低平视——作为一句提示出现，不打断构图。
- **水平仪**：像 iPhone 一样，只在接近水平时出现，调平后变黄并消失。
- **一行提示**：取景画面只保留一句当前步骤的提示；构图完成后再给一条姿势 / 角度建议；没有主体时给场景拍摄建议（如「夜景：拿稳手机」）。
- **清晰度**：最高分辨率、最高画质拍摄；没有任何处理时直接保存相机原始 JPEG，按快门先对焦主体、等手机稳住再拍；支持厂商画质增强（HDR / 夜景）的手机会自动启用；拍完检查是否糊了。相册点评里会写明每张照片自动做了哪些处理。
- **云端 AI 构图建议**（可选，需要自己的 API Key）：点顶部「AI建议」，把当前画面发给云端视觉大模型（默认通义千问 qwen3.7-plus，也支持豆包或其他 OpenAI 兼容接口），它会描述画面、指出问题、给出最重要的一条建议和姿势建议，并给出推荐取景框——这个框会接到上面的圆点瞄准引导里。长按「AI建议」修改设置。相册里的「AI 点评」可以让大模型点评拍好的照片。
- **App 内相册**：左右滑看照片、分享、删除，查看每张照片拍摄时的识别结果、取景理由和检查清单。
- 其他：网格、语音播报（默认关）、3 秒 / 10 秒定时、音量键拍照、点击对焦、双指缩放。照片保存在相册 `Pictures/AICamera`。

需要 Android 10 及以上。

## 安装

在 GitHub 仓库的 **Releases → latest** 下载 `AICamera.apk`，用手机打开安装（需要允许"安装未知来源应用"）。
每次构建都用仓库里同一个签名，新版本可以直接覆盖安装。

> `keystore/debug.keystore` 是公开的调试签名，只适合自己用，不要拿去上架应用商店。

## 自己编译

需要 JDK 17+ 和 Android SDK（compileSdk 36）。

```bash
./gradlew testDebugUnitTest   # 规则引擎单元测试
./gradlew assembleRelease     # 输出 app/build/outputs/apk/release/app-release.apk
```

国内网络如果下载依赖慢，可以在 `settings.gradle.kts` 的 `repositories` 里加上阿里云镜像。

## 代码结构

- `app/src/main/java/com/aucai/aicamera/core/`：纯 Kotlin 的规则引擎（构图、姿势、光线、水平、提示防抖、评分），有单元测试
- `camera/`：CameraX 帧分析、MediaPipe 姿态识别、重力传感器
- `ui/`：取景叠加层、评分快门按钮、语音播报
- `MainActivity.kt`：界面和相机控制

模型 `pose_landmarker_lite.task`、`efficientdet_lite2.tflite`、`efficientnet_lite0.tflite`、`selfie_segmenter.tflite` 来自 [MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)（Apache 2.0）。
