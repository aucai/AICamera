# AI拍照助手

一个安卓相机 App，拍照时实时给出**构图、姿势、光线**建议。AI 模型（MediaPipe 人体姿态识别）在手机本地运行，不联网。

## 功能

交互参考了华为「AI 辅助构图」、三星「Shot suggestions」、OPPO「LUMO 灵感构图」和 iPhone 水平仪：

- **瞄准式构图**：识别到主体（人物、猫狗、食物、花草等 80 类物体、风景地平线）后，算一次推荐构图并锁定。画面中间有一个固定的圈，场景里有一个目标点（跟着场景走）。移动手机把圆点对进圈里 → 变黄并轻震 → 保持不动，相机自动拉近焦距完成构图。
- **双构图**（拍人时）：「人物特写」会拉近突出人物，「人景合一」不变焦、把人放在环境的三分线上。
- **角度引导**：需要时出现两个圆，引导调整俯仰角——拍全身微微仰拍更显高，拍美食斜 45°，拍宠物蹲低平视。
- **水平仪**：像 iPhone 一样，只在接近水平时出现，调平后变黄并消失。
- **对准后自动美化**（顶部「美化」开关，默认开）：圆点对进圈、拉近完成后——
  - **自动裁剪**：按场景选画幅（美食 / 花草 1:1，横拿拍风景 16:9，其余保持原比例），再按三分法微调位置；框外实时压暗，看到的就是存下来的。
  - **自动调光**：以人脸为准（没有人就看整体）每次调 1/3 档曝光补偿，最多 ±2EV；过曝就压暗。
  - **自动补光**：逆光或暗光下拍离得不远的人时自动打闪光灯（前置用屏幕补光）；其余情况在照片里做暗部提亮。
  - **自动滤镜**：人像「自然」、美食「美味」、风景 / 花草「鲜艳」、宠物 / 物品「清新」，取景画面实时生效。点顶部「滤镜」标签可以手动切换（原图、胶片、黑白等），手动选的滤镜会一直生效。
  - 相册点评里会写明这张照片自动做了哪些处理。
- **自动测光**：检测到人就自动对人脸测光，逆光时显示「逆光优化」。
- **一行提示**：取景画面只保留一句当前步骤的提示；构图完成后再给一条姿势建议。
- **清晰度**：最高分辨率、最高画质拍摄；没有裁剪 / 滤镜时直接保存相机原始 JPEG（有的话只解码裁剪区域、全分辨率处理），按快门先对焦主体、等手机稳住再拍；支持厂商画质增强（HDR / 夜景）的手机会自动启用；拍完检查是否糊了。
- **云端 AI 构图建议**（可选，需要自己的 API Key）：点顶部「AI建议」，把当前画面发给云端视觉大模型（默认通义千问 qwen3.7-plus，也支持豆包或其他 OpenAI 兼容接口），它会描述画面、指出问题、给出最重要的一条建议和姿势建议，并给出推荐取景框——这个框会接到上面的圆点瞄准引导里。长按「AI建议」修改设置。相册里的「AI 点评」可以让大模型点评拍好的照片。
- **App 内相册**：左右滑看照片、分享、删除，查看每张照片拍摄时的识别结果、取景理由和检查清单。
- 其他：网格、语音播报（默认关）、3 秒 / 10 秒定时、音量键拍照、点击对焦、双指缩放。照片保存在相册 `Pictures/AICamera`。

需要 Android 10 及以上。

## 安装

在 GitHub 仓库的 **Releases → latest** 下载 `AICamera.apk`，用手机打开安装（需要允许"安装未知来源应用"）。
每次构建都用仓库里同一个签名，新版本可以直接覆盖安装。

> `keystore/debug.keystore` 是公开的调试签名，只适合自己用，不要拿去上架应用商店。

## 自己编译

需要 JDK 17+ 和 Android SDK（compileSdk 36）。

```bash
./gradlew testDebugUnitTest   # 规则引擎单元测试
./gradlew assembleRelease     # 输出 app/build/outputs/apk/release/app-release.apk
```

国内网络如果下载依赖慢，可以在 `settings.gradle.kts` 的 `repositories` 里加上阿里云镜像。

## 代码结构

- `app/src/main/java/com/aucai/aicamera/core/`：纯 Kotlin 的规则引擎（构图、姿势、光线、水平、提示防抖、评分），有单元测试
- `camera/`：CameraX 帧分析、MediaPipe 姿态识别、重力传感器
- `ui/`：取景叠加层、评分快门按钮、语音播报
- `MainActivity.kt`：界面和相机控制

模型 `pose_landmarker_lite.task` 来自 [MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)（Apache 2.0）。
